# Histórico preservado

Esta pasta contém código e materiais anteriores. Não é carregada pelo site nem copiada para o build.

- `pre-vite/`: implementação antes da migração para TypeScript + Vite.
- `refactor/`: CSS e módulos antes da reorganização atual.
- `previous-materials/`: imagens, capturas e marcas antigas que não são usadas na página.

Os retratos originais atuais ficam em `assets/originals/portraits/`. Para manutenção, use os arquivos ativos em `src/`, `public/` e o `index.html` da raiz.
